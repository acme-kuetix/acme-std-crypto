# acme-std-crypto

Password-hashing primitives callable from WSL workflows — a reusable extension package in the `acme-std-*` family.

## Import

```
import github.com/acme-kuetix/acme-std-crypto
```

## WSL-callable transitions

`modules/crypto/transitions/crypto.go` exposes two transitions:

- `Hash(value: $json.password)` — bcrypt-hash a password. Returns `{hash: string}`.
- `Compare(value: $json.password, hash: $user.passwordHash)` — verify a password against a stored bcrypt hash. Returns `{valid: bool}`.

Action path format (service namespace `crypto`, transition namespace `crypto`):

```
crypto/crypto.Hash(value: ...)
crypto/crypto.Compare(value: ..., hash: ...)
```

## WSL usage

```
import crypto

state Register {
  action acme-std-crypto/crypto.Hash(
    value: $json.password
  ) as Hashed
  on success -> Store
}
```

## Package-level helpers (Go callers only)

`HashVal(password)` and `SignVal(secret, message)` are exported package-level
functions intended for direct Go callers — they are **not** WSL transitions
and cannot be invoked from a `.wsl` file.
